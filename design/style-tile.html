01

The look

Black-and-white film, surveillance footage, and editorial magazine — Aimé Leon Dore × Off-White × Aesop. Confident, refined, characterful. Generous negative space. Sharp hairlines. Deliberate grain. Restraint reads as expensive.

Refined minimalism only works through precision. Spacing is exact. Typography is deliberate. Motion is choreographed. Every detail is intentional — otherwise it reads as AI slop.

03

Typography

Boldonse for display — heavy, geometric, brutalist caps energy. Streak counters, screen titles, gym names. Geist for body and UI — a modern grotesk with character. Italic Geist is reserved for empty-state copy and pull quotes.

Banned: Inter, Roboto, Arial, San Francisco, Space Grotesk, Poppins. They're too common and they kill the aesthetic.

05

Details that earn it

The aesthetic dies if these are missed. Each must be implemented exactly.

05.1

Grain overlay

SVG fractal noise rendered at 4–5% opacity over the entire app, applied at the root layout. Adds the "film stock" character that distinguishes this from a generic dark theme.

Skia · perlin · opacity 0.04
05.2

1px hairlines

Every divider, card edge, sheet handle, and bottom border uses a single 1px stroke in iron. Never thicker. Never doubled. The discipline of the hairline carries the entire interface.

1px solid #27272A
05.3

Photo treatment

Posts render with 0 corner radius — full bleed and rectangular. 1px iron border + a tight inset shadow at 40% black. Reads as printed-on-paper, not floating glass.

radius 0 · inset shadow
05.4

Square avatars

Avatars use 4px corners, not circles. Circles are the universal "generic social app" tell. Squares with subtle rounding read as editorial. DM headers are the one exception.

radius 4px
05.5

Verified mark

A small white-fill circle with a black checkmark — never green. Inverted from the surrounding palette so it asserts itself without color. Premium gets a thicker outline-only stroke instead of a fill.

22px · #FAFAFA fill
05.6

Streak flame

Skia-rendered flame with white-to-fog radial gradient and subtle ember particles in mist. Continuous breathing scale (1.0 → 1.03 → 1.0) at 2.4s. Never orange.

white → fog · breathing 2400ms

07

Aesthetic test

If a screen wouldn't feel at home next to an Aimé Leon Dore lookbook page or an Aesop product page, redo it. If a screenshot of the screen could be from a generic Cursor demo video, redo it.

Do
Commit to the monochrome palette. No exceptions.
Use Boldonse for any number that wants to dominate.
Set big numbers in Boldonse and let them dominate their card.
Use generous negative space. Empty states use 1/3 of the screen for whitespace alone.
Use asymmetric compositions. Place text bottom-left or top-right.
Use 1px hairlines in iron everywhere. Never thicker.
Use square 4px-radius avatars. Photos full-bleed and rectangular.
Hand-tune empty, loading, and error states for every list. Never default.
Add the grain overlay at the root. It's the difference between dark theme and editorial.
Use weight, opacity, and texture to differentiate states. Never hue.
Hide identities with heavy blur + grayscale. Curiosity is the engine — never replace it with a cold counter.
Don't
Use Inter, SF Pro, Roboto, Space Grotesk, or Poppins. Anywhere.
Add color accents — flame orange, electric green, status colors. Banned.
Use circular avatars outside DM headers.
Use shimmer skeletons. Use a still grain overlay with a single Boldonse word instead.
Use gradients, except the Skia flame's white-to-fog radial.
Use glassmorphism, frosted blur, or any "iOS-glass" effect.
Use bouncy springs everywhere. Use cubic-bezier easings.
Use rounded-full pills for content. Reserve them for status only.
Center everything. Asymmetry is a feature.
Use red for errors, green for success. Use copy weight and texture instead.
Show timestamps next to viewers. Reads as surveillance.
